## 💡 About

Complete source code for the site deployed at https://codaglot.skjorn.name

Some content and configuration are stripped, but the functionality of the version released on December 25, 2025 is available to full extent.

The visuals are fully customized, based on my own design.

Also, if you know someone who'd like to learn Kotlin and has some programming experience already, please share the site with them. More languages are coming.
